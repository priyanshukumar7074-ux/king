# Private Messaging Application

## Overview
This private messaging application allows users to send and receive messages securely. It aims to provide a simple and intuitive user interface along with robust messaging features.

## Features
- User registration and authentication
- Send and receive messages in real-time
- Message encryption for enhanced security
- User profiles
- Group messaging capabilities

## Installation
To install the application:
1. Clone the repository: `git clone https://github.com/priyanshukumar7074-ux/king.git`
2. Navigate to the directory: `cd king`
3. Install dependencies: `npm install`
4. Run the application: `npm start`

## Usage
After starting the application, users can:
- Create an account or log in.
- Navigate to their inbox to view received messages.
- Compose and send new messages to other users.
